# Noto Sans Fonts

This directory contains bundled open-source font files used by Sharp for deterministic serverless carousel image rendering.

- **Font Family**: Noto Sans
- **Styles**: Regular (400), Bold (700)
- **Source**: Google Fonts / Google Noto Fonts repository (`https://github.com/googlefonts/noto-fonts`)
